# IT326-Data-mining-Project
##Project Description
This project analyzes the Mushroom dataset to investigate whether the physical characteristics of a mushroom can be used to distinguish edible mushrooms from poisonous ones. The dataset contains categorical features describing different parts and properties of mushrooms, including cap shape, cap surface, cap color, odor, gill characteristics, stalk characteristics, veil and ring properties, spore-print color, population, and habitat. The project will apply classification techniques to predict whether a mushroom is edible or poisonous and clustering techniques to group mushrooms with similar physical characteristics. The resulting clusters will also be examined to determine how closely the discovered groups correspond to the known edibility classes.
## Motivation 
We chose this dataset because mushrooms have a wide variety of physical characteristics, which makes them interesting to analyze and compare. Studying these characteristics is important because some mushrooms may share similar features while having different levels of edibility. Analyzing the data can help discover useful patterns, show similarities between mushrooms, and identify features related to whether they are edible or poisonous.
